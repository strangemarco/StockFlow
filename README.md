# StockFlow

StockFlow es un sistema web para la gestión de inventario, ventas y compras, diseñado con una interfaz moderna y funcionalidades completas para el control de un negocio.

## Características y Módulos

El sistema está compuesto por los siguientes módulos principales:

*   **Dashboard:** Panel principal con un resumen general de las actividades, estadísticas y métricas importantes.
*   **Inventario:** Gestión y control del stock disponible.
*   **Ventas:** Registro de nuevas ventas, historial de transacciones y facturación.
*   **Compras:** Registro de compras a proveedores y abastecimiento de inventario.
*   **Productos:** Administración del catálogo de productos, precios y detalles.
*   **Categorías:** Organización de los productos por categorías y subcategorías.
*   **Personas (Clientes y Proveedores):** Directorio de contactos para las operaciones comerciales.
*   **Reportes:** Generación de informes sobre ventas, compras, inventario y rendimiento del negocio.
*   **Usuarios:** Gestión de cuentas de acceso al sistema y roles.
*   **Configuración:** Ajustes generales del sistema.

## Tecnologías Utilizadas

*   **Frontend:** HTML5, CSS3, JavaScript Vanilla
*   **Estructura:** Modular, separando lógica de datos (`assets/js/data`), módulos de interfaz (`assets/js/modules`) y utilidades comunes (`assets/js/utils`).

## Estructura del Proyecto

*   `/assets`: Contiene recursos estáticos como hojas de estilo (`css/`) y scripts (`js/`).
*   `/pages`: Contiene las diferentes vistas HTML divididas por módulos (dashboard, ventas, inventario, etc.).
*   `index.html`: Punto de entrada de la aplicación (Login/Inicio).
